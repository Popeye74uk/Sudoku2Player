🔍 Connection Troubleshooter

  1. Step 1: Test with your phone's browser
    Open your phone's web browser and type this exact URL: http://192.168.1.71:8080/api/ping
    • If it displays a JSON response (like {"success":true,...}), the link is open! Close the browser and scan the QR code.
    • If it spins forever or says "Site unreachable", then the network path is blocked by a Firewall or Router. Proceed to Step 2.
  2. Step 2: Check Windows Firewall Override Block
    Sometimes Windows has a specific "Block" rule for node.exe from previous prompts that overrides the port rule. To check: Search Windows for "Allow an app through Windows Firewall", click "Change settings", scroll down to Node.js JavaScript Runtime, and ensure both Private and Public boxes are checked.
  3. Step 3: Enable Windows Mobile Hotspot (100% Success!)
    Many routers block Wi-Fi devices from talking to each other (AP Isolation). You can bypass this completely:
    1. In Windows, search and open "Mobile Hotspot settings" and turn it ON.
    2. Connect your phone/tablet to this new Hotspot Wi-Fi network.
    3. Refresh this page to update the QR code and scan it to play instantly!
